## Energy Convention

Use pack amp-hours for the primary endurance energy comparison.

- `Charge used (net)` = integral of pack current over time, with regen subtracted.
- `Energy consumed (net)` = integral of pack voltage times pack current over time, with regen subtracted.
- The AiM/BMS `State of Charge` channel is only a displayed estimator. It is not a true measured energy value and is not a validation pass/fail metric.
- Sim SOC remains an internal battery-model state for voltage, current limits, and termination logic.

## Honest Interpretation

The simulator is useful today for replay analysis and rough parameter sensitivity, especially for pack-current and energy accounting. It is not yet a fully predictive tune optimizer.

For max torque vs RPM sweeps, the current tool can identify trends only if the driver model and track assumptions are held fixed. Treat exact lap-time deltas as provisional until the prediction path has:

- A driver model that adapts braking and throttle to the changed torque/RPM envelope.
- A current-limited speed envelope that uses the same powertrain and battery limits as runtime.
- An independent or explicitly accepted track model for the current event.
- CT17EV config values that are measured or clearly marked as assumptions.
- Validation against holdout laps using net Ah, net kWh, speed trace, voltage, current, and temperature.

## Known Remaining Issues

- Calibrated mode is still 7.3% too fast on the full validation run.
- The current track model is still built from telemetry GPS, not from an independent surveyed track or cone map.
- CT-16EV tire grip uses a Michigan 2025 empirical `grip_scale`; prediction mode correctly refuses it unless empirical grip is explicitly allowed.
- The current driver strategy compresses telemetry into segment zones. That is not the same thing as a predictive driver reacting to a new torque/RPM tune.
- The engine and speed envelope still need tighter unification around current limits, braking, and combined slip before exact optimization results should be trusted.
